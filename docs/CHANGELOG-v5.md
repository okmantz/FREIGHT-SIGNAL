# v5 changes

- One **Target rate** per load (matrix). It is posted as the DAT rate and judges carrier replies. "Post target rate on DAT" on the board toolbar turns the CSV rate off; a per-posting DAT rate override remains in each posting's Edit dialog.
- Cleaner load card: status badge, issue chips, load details bar (pickup, weight, equipment, target rate), options row, one **Carrier outreach** button per load, compact A-A..C-C matrix table with a per-row ⋯ menu.
- Lane scan is one switch per load (on the A-A posting) instead of nine per-posting Yes/No cells.
- 17 photo backgrounds (dark + light) with matching animated effects (leaves, snow, petals, rain, fireflies, ...). Clean, gradient and your own image are kept.
- Account Settings sections are collapsed by default. New **Sign-in & e-mail** section.
- First launch asks for an e-mail and password (or Skip for now). Sign-in is local to the browser: a door lock, not a vault, and it does not sync across devices.
- Overviews trimmed to the four numbers that matter (three on Home).
- The single-file build (dist/freight-signal.html) cannot show photo backgrounds under its strict CSP; use the hosted app for those.
